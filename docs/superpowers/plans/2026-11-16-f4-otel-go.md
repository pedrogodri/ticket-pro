# F4 OpenTelemetry (Go) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Bônus 3 nos serviços Go (gateway, inventory, notification):
- exportar traces OTLP para o collector;
- spans `producer`/`consumer` nas mensagens;
- auto-instrumentação HTTP e DB.

O trace de uma requisição deve aparecer no Jaeger atravessando o gateway e o serviço Go de destino.

**Architecture:**
- `shared/go/tracing.Setup` instala o TracerProvider global com exporter OTLP/gRPC e o propagador W3C. Sem `OTEL_EXPORTER_OTLP_ENDPOINT`, nada é exportado.
- O relay abre um span `producer` filho do `traceparent` gravado no outbox e publica o `traceparent` do próprio span.
- O consumer abre um span `consumer` filho do `traceparent` da mensagem, com um link para o mesmo contexto (ADR-0012).
- Nos serviços:
  - `otelhttp` envolve os servidores HTTP e, no gateway, também o transporte para os upstreams, o que propaga o `traceparent`;
  - `otelpgx` instrumenta os pools do inventory e do notification.

**Tech Stack:** go.opentelemetry.io/otel v1.46.0, otlptracegrpc v1.46.0, otelhttp v0.71.0, otelpgx (versão compatível com otel 1.46).

**Spec:** `docs/adr/0012-opentelemetry-collector-jaeger.md`, roadmap F4 item 3, RFC 0001 §5.2.

## Global Constraints
- Configuração só por env: `OTEL_EXPORTER_OTLP_ENDPOINT` (ex.: `otel-collector:4317`) e `OTEL_SERVICE_NAME`, com padrão `SERVICE_NAME`.
- Mudanças em `shared/go` são sincronizadas com `scripts/sync-shared.sh`; não editar as cópias.
- O `correlationId` continua independente do trace.

## Review Focus
1. **Mensagem sem `traceparent`** → o consumer abre um span raiz, sem erro. Teste na Task 1.
2. **Collector fora do ar** → o serviço sobe e atende normalmente, com export assíncrono. Teste na Task 1 (Setup com endpoint inalcançável não bloqueia).
3. **O `traceparent` enviado ao upstream pelo gateway** é o do span do gateway, não o que o cliente mandou sem validação. Teste na Task 2.
4. **O span do consumer termina com erro** quando o handler falha (transient/poison). Teste na Task 1.
5. **Shutdown** faz flush dos spans pendentes. Coberto pelo `Shutdown` retornado por `Setup`, chamado no `main`.
