# Gateway (Go): plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (ou subagent-driven-development) para executar tarefa a tarefa, e superpowers:test-driven-development em cada uma. **Este plano só descreve trabalho: nenhum código, migration, teste ou script foi escrito ao produzi-lo.**

**Goal:** Entregar o fechamento do `gateway` (já completo segundo o [plano anterior](2026-11-15-gateway-complete.md)): **rota `POST /auth/refresh` pública**, testes de superfície da fronteira e revogação verificada com o `TokenRevoked` do auth real, até o **freeze de ter 24/11 às 12h**.

**Architecture:** Mudanças pequenas em `cmd/gateway/main.go` (mapa `Public`) e testes em `internal/proxy` ([RFC 0010](../../rfc/0010-design-do-gateway-em-go.md)). Sem camada nova.

**Tech Stack:** Go 1.25, `golang-jwt/jwt/v5`, Redis (`gateway-redis`), `internal/platform` vendorizada (não editar).

**Spec:** [RFC 0010](../../rfc/0010-design-do-gateway-em-go.md); [RFC 0002 §5.5, §5.8](../../rfc/0002-authentication-and-authorization.md); [ADR-0002](../../adr/0002-gateway-validates-jwt-locally-via-jwks.md), [ADR-0014](../../adr/0014-token-revocation-via-event.md); [padrões](../../padroes.md) §2.1, §4.

## Global Constraints

- **Branch:** `feat/gateway-<descrição>` (ou `fix/gateway-...`); nunca na `main`; sem push sem pedir; sem worktree. Commits `fix(gateway): ...`.
- **Nunca editar** `internal/platform/` nem `contracts/`.
- **Sem rota nova sem tabela:** toda rota pública está num mapa explícito com teste.
- **Env, não hardcode:** limites e timeouts por env, já documentados.
- **Definition of Done:** `cd services/gateway && make lint typecheck test` verde; `scripts/gateway-check.sh` exit 0; README atualizado.
- **Ownership:** Pedro (também dono de notification e autoscaler: ver [Riscos](#riscos)).

## Review Focus

1. A lista pública é só `register`, `login`, `refresh`; `logout` exige Bearer.
2. Nenhum header de identidade do cliente sobrevive.
3. `/.well-known/*` e `/health/*` não chegam a um upstream por prefixo.

## Tarefas

### G01: `POST /auth/refresh` pública

- **Owner:** Pedro. **Depende de:** nada.
- **Files:** `services/gateway/cmd/gateway/main.go` (mapa `Public`), `internal/proxy/proxy_test.go`.
- **Passos (TDD):** [ ] Teste: `POST /auth/refresh` sem Authorization chega ao upstream com rate limit por IP; `POST /auth/logout` sem Bearer → 401 (e **não** vai ao upstream). [ ] Incluir a rota em `Public`.
- **Pronto quando:** `make test` verde; `gateway-check.sh` ainda verde.
- **Valida:** `scripts/gateway-check.sh`. **Mapeia:** RFC 0002 §5.5.

### G02: Testes de superfície

- **Owner:** Pedro. **Depende de:** G01.
- **Passos:** [ ] `alg=none` e HS256 → 401 (conferir cobertura em `TestVerify_RejectsTamperedTokens`; acrescentar o que faltar). [ ] `GET /.well-known/jwks.json` e `GET /health/live` pelo gateway não alcançam nenhum upstream (404/handler próprio). [ ] `GET /outro` → 404. [ ] Conferir no `docker-compose.yml` a ordem `depends_on` gateway/auth.
- **Pronto quando:** testes verdes; relatório do compose (se houver ajuste, vira tarefa do dono do compose).
- **Valida:** `make test`; `scripts/check-ports.sh`. **Mapeia:** API5/API9.

### G03: README

### G04 (Should): Revogação com logout real

- **Owner:** Pedro e Felipe. **Depende de:** A03.
- **Passos:** [ ] Estender `gateway-check.sh` (ou usar `auth-check.sh`) para que o `TokenRevoked` venha do `POST /auth/logout`, não de publicação manual. [ ] Medir a latência logout → 401 (esperado < 1 s).
- **Pronto quando:** exit 0; latência registrada no runbook. **Valida:** `scripts/gateway-check.sh`, `scripts/auth-check.sh`. **Mapeia:** ADR-0014.
